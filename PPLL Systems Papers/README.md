# PPLL Systems Papers

Public proof-of-work papers from **Paranoid People Live Longer (PPLL)**.

These papers document distinct systems developed through sustained practical work with AI, documents, research, business operations, evidence, and human-controlled decision making. Each paper is written to stand on its own. The collection is intentionally small: a new paper belongs here only when it represents a materially different system rather than another variation of an existing one.

## File format

Each paper folder contains the same public edition in two forms:

- **PDF** for immediate reading and browser review.
- **DOCX** as the editable document edition.

The PDF and DOCX use the same base filename so the relationship between representations stays obvious.

## Collection principle

The point of these papers is not to make AI look autonomous. Across the collection, the recurring design questions are practical: what state must survive, what evidence supports a claim, what can be delegated, what still requires human authority, what counts as completion, and how a system recovers when it fails.

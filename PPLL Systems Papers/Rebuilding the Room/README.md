# Rebuilding the Room

**Public Systems Paper v1.2**

Reconstructing useful AI collaboration across model changes without changing model weights. The paper separates model capacity, platform constraints, and externally controllable operating conditions such as state handling, response shape, evidence discipline, human authority, and recovery.

# The Work Survives the Session

**Public Systems Paper v1.0**

A continuity and handoff architecture for long-running AI-assisted work. It externalizes authority, evidence state, versions, decisions, unresolved gaps, and recovery paths so a new chat, model, tool, or human operator can resume without pretending memory is proof.

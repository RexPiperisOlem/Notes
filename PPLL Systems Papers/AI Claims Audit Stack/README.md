# AI Claims Audit Stack

**Public Systems Paper v1.1**

An evidence-bounded framework for examining claims produced by AI, supported by AI, evaluated with AI, or presented as if AI independently established the conclusion. The public paper focuses on provenance, evidence access, measurement, recourse, generalization, and human accountability.

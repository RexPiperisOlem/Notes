# From Conversation to Controlled Work

**Public Systems Paper v1.0**

A translation architecture that turns natural conversation into bounded work. It separates signal, mode, objective, state, constraints, authority, work order, execution gates, verification, and return so the human does not have to pre-format ordinary speech into machine-shaped prompts.

# Published Documents

## About the builder

Roger Crosby is an Ottawa-based systems builder and operational writer working across human-gated artificial intelligence, documentation, evaluation, creative systems, and public artifacts.

The work is developed through repeated testing, explicit constraints, preserved evidence, and human review. The objective is not to make systems appear intelligent. It is to make them understandable, inspectable, and useful.
